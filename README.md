# ColorToMQTTApp

⚠️ **Приложение находится в активной разработке.**

Spring Boot приложение, которое публикует цветовые данные в MQTT-брокер.

## 📦 Стек технологий

- Java 22  
- Spring Boot 3.4.2  
- MQTT (Eclipse Paho)  
- Thymeleaf  
- Log4j2  
- YAML конфигурация  
- Lombok

## 🔧 Возможности

- Веб-интерфейс для выбора цвета (через Thymeleaf)
- Публикация выбранного цвета в MQTT-брокер
- Поддержка YAML-конфигураций
- Log4j2 для логирования
